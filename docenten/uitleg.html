Wat is deze website?

[SITE-NAAM] is een lessenserie over sterrenkunde voor groep 7 en 8. Elke les heeft een korte tekst met afbeeldingen en een spel. Moeilijke woorden zijn aan te tikken, zodat leerlingen de uitleg direct zien. [Lorem ipsum dolor sit amet, hier komt een uitgebreidere beschrijving.]

Hoe werkt de klascode?

Bij elke klas hoort een code van 6 tekens. Je geeft de code aan je leerlingen. Zij vullen de code in op de startpagina, controleren of de klas klopt en typen hun voornaam. Hoofdletters of kleine letters maken niet uit.

Aangemelde leerlingen blijven bewaard, zodat je altijd kunt zien wie er heeft meegedaan. Met "Nieuwe code genereren" maak je een nieuwe code. De oude code werkt dan niet meer, maar leerlingen die al zijn aangemeld blijven in de klas.

Welke lessen zien leerlingen?

Jij kiest per klas het toegangsniveau:

  • Les 1: alleen les 1.
  • Les 1 t/m 2: les 1 en 2.
  • Les 1 t/m 3: les 1, 2 en 3.
  • Volledige toegang: alle lessen, plus de zoekpagina en de verdiepingsartikelen.

Je kunt het niveau op elk moment aanpassen, bijvoorbeeld na elke les een les extra openen.

Zo gebruik je de lessen in de klas

  1. Maak een klas aan op de pagina Klassen en kies het toegangsniveau.
  2. Geef de klascode aan je leerlingen, bijvoorbeeld op het bord.
  3. Lees de aanwijzingen bij de les op de pagina Lessen.
  4. Laat de leerlingen de les lezen en het spel spelen.
  5. Bekijk daarna op de pagina Voortgang hoe het ging.
